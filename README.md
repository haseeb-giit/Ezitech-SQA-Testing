# Ezitech-SQA-Testing

Documentation of SQA work done during my internship at Ezitech Institute — covering test planning, test case design, and quality verification for the EziTech Supervisor Portal, based on its IEEE 830-1998 SRS specification.

## About This Repository

This repository contains the complete Software Quality Assurance (SQA) work carried out over a **9-week internship** at **Ezitech Institute** (a subsidiary of Eziline Software House) as part of the Quality Assurance role, working on the **EziTech Supervisor Portal** project.

All documentation and testing artifacts in this repository were **independently researched, designed, and written from scratch**. No proper SQA documentation existed for this project prior to this work — whatever documentation was previously available was incomplete and did not follow any recognized standard. Every SRS and test case document here was built following the **IEEE 830-1998** standard for software requirement specifications and standard SQA test case design practices.

## Project Scope

The EziTech Supervisor Portal has three main user roles, and SQA documentation was prepared separately for each:

- **Intern Module** — SRS and test cases covering intern-level functionality
- **Manager Module** — SRS and test cases covering manager-level functionality
- **Supervisor Module** — SRS and test cases covering supervisor-level functionality

## Work Summary

Over the course of the internship, the following SQA activities were performed for each module of the portal:

- Gathered and analyzed functional and non-functional requirements
- Documented complete Software Requirement Specifications following the IEEE 830-1998 standard
- Designed detailed test cases covering functional flows, edge cases, and validation scenarios
- Reviewed and verified requirement-to-test-case traceability for quality assurance
- Structured and standardized documentation where none previously existed in a usable form

## Note

This work was completed individually, with no pre-existing standardized documentation to build upon.
